05 / Editor

In Cursor and VS Code, too.

A separate extension. The status bar shows Cursor usage without opening the menu bar app. It reads the Cursor login already stored here, not your code, prompts, or chats.

  1. Download the extension.
  2. In Cursor or VS Code, open Extensions, then Install from VSIX.
  3. Run AI Meter: Use This Cursor Login. Paste Token is there if that misses.
