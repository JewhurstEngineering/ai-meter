It uses the login already on this Mac.

Tokens stay in the Keychain. The phone and the watch get a sanitized snapshot, not credentials. AI Meter does not scrape dashboards, and it does not put tokens in iCloud.

  1. Sign in with Cursor in the app, or connect from the Cursor IDE.
  2. Add Claude Code from the keychain or ~/.claude/.credentials.json.
  3. Add Codex from ~/.codex/auth.json.
  4. Or paste a Cursor token if the window and the IDE both miss.
